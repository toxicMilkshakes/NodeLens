# NodeLens

Windows 桌面与任务栏 VPN 状态小窗，显示节点、HTTP 延时和实时上下行速度。

## 功能

- Clash Verge：自动发现运行中的 Mihomo 管道，也支持本机 HTTP 接口。
- 紧凑单行任务栏显示、桌面悬浮窗、拖动、右键设置和退出。
- 无系统托盘图标，支持 `--silent` 静默启动到任务栏。
- 断线后清空过期数据并自动重试，不使用截图或 OCR。
- 接口密钥用当前 Windows 用户的 DPAPI 加密保存在本机。

## 构建与运行

需要 Windows 10/11 x64 和 .NET Framework 4.8。使用 Windows 自带的 C# 编译器，无需下载第三方依赖。

```powershell
.\build.ps1
.\bin\Tests.exe .\bin\test-results.txt
.\bin\NodeLens.exe
```

右键小窗选择“显示在任务栏”；右键任务栏数据可打开设置、切回悬浮窗或退出。任务栏模式在 Windows 11 25H2 实测，使用非官方任务栏子窗口方式，系统更新可能影响兼容性。当前仅适配主屏横向任务栏，图标较多时应留意空间。

登录自启动：在设置中勾选“开机自启动（登录后显示在任务栏）”，点击“保存并重连”生效。关闭开关并保存即可取消。开关管理当前用户注册表 Run 项，无需管理员权限，以 `--silent` 启动。程序文件与 NodeLens.exe.config 应放在固定目录；移动程序后请重新勾选并保存以更新路径。若此前手动在 `shell:startup` 中添加了快捷方式，请自行删除该快捷方式。

## 数据说明与限制

- 显示所关注策略组的节点；规则分流时，不同网站可能使用不同节点。
- 速率是客户端统计的总速率，可能包含直连流量，使用十进制 KB/MB。
- 延时来自客户端近期记录或每 30 秒的 HTTP 204 探测，不是带宽测速。
- 客户端主窗口可以隐藏，但连接内核必须运行。
- 肥猫云 Lite 需要其本地 Clash 接口已启用，尚未完成真实后台兼容验证。
- NordVPN 支持活动专用网卡速率和 HTTP 探测，节点名称未支持，活动连接兼容性未完成验证。

配置保存在 `%LOCALAPPDATA%\NodeLens\settings.json`。缺失数据显示为“—”，不会冒充零速率或旧数据。

## 测试

30 项检查覆盖自启动注册与移除、节点解析、接口认证、命名管道、流量流、断线清空和活动服务管道发现。测试使用本地模拟服务，不切换 VPN 节点或修改订阅。

源码在 `src/`，测试在 `tests/`。本机截图、日志、用户配置、编译产物和与本项目无关的系统工具不纳入仓库。
